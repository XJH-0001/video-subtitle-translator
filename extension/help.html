使用说明

视频实时字幕翻译 · v1.0.0

一句话原理：扩展抓取标签页的声音 → 送到你自己电脑上的本地服务做语音识别和翻译 → 把字幕显示回视频上。音频不会上传到任何服务器，所有识别都在本机完成。 因为浏览器扩展本身做不了语音识别，所以必须有一个本地服务在旁边跑着。

一、每次使用（2 步）

本地服务不用你手动启动了。扩展里点「开启实时字幕」时会自动把它拉起来 （走 Native Messaging，注册由安装脚本完成）。第一次会多等几秒，因为要加载识别模型。

想手动启停也没问题：双击 scripts\start-server.bat 会开一个带日志的窗口， 关掉那个窗口就停。想彻底关掉自动启动，在设置页取消勾选「自动启动本地服务」。

  1. 在 Edge 里打开视频，点一下播放（一定要有声音）。
  2. 点浏览器工具栏上的扩展图标 → 开启实时字幕。字幕会直接浮在视频上。

快捷键：Alt + Shift + S 可以随时开关。再点一次扩展图标里的按钮就停止。

字幕延迟大约 0.5 秒（N 卡加速）或 1.5 秒（CPU）。 弹窗里会显示当前是「显卡加速」还是「CPU 识别」。

有 NVIDIA 显卡？强烈建议开一下

一条命令，字幕延迟能从 1.5 秒降到 0.5 秒以内：

powershell -ExecutionPolicy Bypass -File scripts\enable-gpu.ps1

它装的是 CUDA 运行库（约 1.3GB），不需要装整个 CUDA 工具包。 如果你系统里本来就装过 CUDA 12 + cuDNN 9，跑它会直接说「已就绪」，什么都不用下载。

没有 N 卡也没关系，会自动走 CPU，只是慢一点。

二、调整字幕

字幕默认会自己贴到视频画面上，像视频自带的字幕一样。 扩展会自动找到页面上正在播放的 <video>，算出真实画面区域 （把上下或左右的黑边刨掉），然后把字幕贴在画面底部。 视频移动、缩放、切影院模式、进全屏，字幕都会跟着走。

找不到视频时（比如播放器嵌在 iframe 里）会自动退回「贴在浏览器窗口底部」，不会失灵。

想做什么怎么做
挪位置 弹窗里点「调整位置」，字幕会变成虚线框，拖动即可。按 Esc 或再点一次按钮完成。此时还会用蓝色虚框标出它贴合的视频画面。
贴着窗口底部而不是视频 弹窗或设置里把「字幕位置」改成「窗口底部」。
改字号 / 颜色 / 行数 弹窗里的「快捷设置」，或者右键扩展图标 →「选项」里的「字幕外观」，有实时预览。
只要译文，不要原文 弹窗里取消勾选「显示原文」。
换翻译语言 弹窗里的「翻译成」下拉框。

拖动保存的是「相对视频画面的百分比」，所以换分辨率、换窗口大小、进出全屏之后，位置依然是对的。

三、出问题了？

点开启后提示「连不上本地服务」

  • 先确认 start-server.bat 那个窗口还在、没报错。
  • 在浏览器地址栏打开 http://127.0.0.1:8765/，能看到状态页就说明服务正常。
  • 如果改了端口，扩展设置里的「服务地址」也要一起改，例如 ws://127.0.0.1:8766/ws。

字幕不出来，一直显示「正在加载识别模型」

第一次用某个模型要下载（small 约 250MB）。如果卡住不动，多半是 HuggingFace 下载不通 —— 服务会自动切到 hf-mirror.com 镜像， 但也可以手动指定： 

$env:HF_ENDPOINT = "https://hf-mirror.com"
.venv\Scripts\python.exe app.py

模型下载好之后，之后每次启动都是秒开。

字幕延迟很大 / 电脑很卡

  • 换小一点的模型：scripts\start-server.bat --model base（或者 tiny）。
  • 关了「显示识别速度」这类额外开销没什么用，主要看模型。
  • 如果有 NVIDIA 显卡，装上 CUDA 12 的 cuBLAS + cuDNN 9，服务会自动改用显卡，快很多。

翻译不出来

  • 设置页点「测试翻译」，会逐个列出哪个接口能用、哪个不行。
  • 免费接口会被限流（尤其 MyMemory），等一会儿或者换个服务。
  • 想要稳定质量：设置里填个 DeepSeek / 通义 / DeepL 的 Key，走 openai 或 deepl。
  • Google 翻译在国内直连不通，属于正常现象，会自动跳过。

开始字幕后视频没声音了

正常情况不会 —— 捕获到的音频会被接回扬声器。如果真没声音， 检查是不是把系统音量 / 标签页静音了，或者先停掉字幕再用一次。

全屏时看不到字幕

字幕通过浏览器的「顶层」机制显示，正常全屏也能看见。 如果某些网站就是不行，试试在设置里把「距底部」调大一点，或者退出全屏用影院模式。

提示「浏览器内置页面无法捕获音频」

edge:// 开头的设置页、扩展商店页、新标签页都不允许捕获音频， 这是浏览器的限制。切到普通网页（B 站、YouTube、网课平台）再用。

四、支持哪些网站

任何用普通网页播放视频的网站都行：B 站、YouTube、腾讯视频、爱奇艺、优酷、Netflix、 各类网课和会议回放等。不支持的：浏览器内置页面、部分使用特殊加密播放器的网站 （这类网站的声音不走标准音频通道，抓不到）。

五、性能参考

模型大小纯 CPU 表现（8 核）适合
tiny~40MB非常流畅只要能听懂个大概
base~75MB流畅老电脑 / 只求实时
small~250MB大约 3~6 倍实时，够用默认推荐
medium~750MB可能跟不上实时有显卡再用
large-v3~1.5GB纯 CPU 不建议有 N 卡，追求准确率

「实时率 RTF」小于 1 就表示识别比视频播放还快，不会越积越多。 开字幕时页面上会显示这个数字。

六、想彻底卸载

  1. 在 edge://extensions 里移除扩展。
  2. 关掉本地服务窗口。
  3. 删掉整个项目文件夹即可（模型缓存在 server\models 里）。
